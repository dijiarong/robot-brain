## Project Requirements

### Goal

创建一套 Go2 原生技能，映射到已有的 `drive(vx, vy, vyaw, duration)` 原语，通过完整的安全链路（clamp → precondition → 分段 drive → post-verify → audit）暴露给 LLM 作为可调用 tool。每个技能只做一件确定的事，速度和距离受限，不开放 raw `drive`。

### Existing Baseline

第十次迭代完成后：

- 执行层（第九次）：`drive()` 带 motion lease、generation 抢占、watchdog、try/finally 归零、前置检查、后验、审计；**单次 `duration` 被 clamp 到 `RDB_UNITREE_MAX_DRIVE_DURATION`（默认 0.5s）**
- 感知桥接（第十次）：`WorldState.robot_self_state` 含 is_standing、is_moving、error_code、sport_mode、velocity、imu_rpy、state_age_seconds
- 技能注册表：`SkillRegistry` 支持注册任意 `Skill` 子类，暴露 JSON Schema 给 LLM
- 安全校验：`SafetyValidator` 按 skill 名称白名单 + 参数限速/限距 + 急停/低电否决 + 确认要求
- 现有 generic 技能：`navigate`/`patrol` 调用 `move_to()`（WebRTC transport 拒绝 `move` 动作）；`follow`/`dock` 在 `UnitreeRobot` 上直接 `NotImplementedError`

本轮不修改现有 generic 技能，不修改 `RobotInterface` 抽象。Go2 技能在 `execute()` 内通过 `isinstance(robot, UnitreeRobot)` 调用 `drive()`。

### Features

- **nudge** — 短距平移。方向 forward/back/left/right，距离 **10–50 cm**（skill 内 clamp），**分段** `drive` 完成总距离
- **scan** — 原地旋转观察。角度 **±90°**（skill 内 clamp），**分段** `drive(vyaw)` 完成总角度
- **retreat** — 后退 **10–100 cm**，始终 vx 负值，**分段** `drive` 完成总距离
- 共享 helper `go2_motion.py`：前置检查、参数 clamp、分段计划、`UnitreeRobot` 类型守卫、异常→`SkillResult`
- 每个 skill 执行全链路：参数 clamp → `robot_self_state` 前置检查 → 多段 `drive()`（每段 ≤ max_drive_duration）→ 依赖第九次 post-verify → 审计写入 `SkillResult.data`
- 技能注册到 `SkillRegistry`；`robot_backend == "unitree"` 时与 generic 技能合并
- `SafetyValidator._validate_motion()` 新增 nudge/scan/retreat 参数上限校验
- **`RDB_PERCEPTION=unitree` 为推荐配置**（否则 `robot_self_state` 为 None，Go2 技能前置检查会拒绝）
- live 实机：`nudge`/`scan`/`retreat` 默认加入 `require_confirmation_for`（与第九次操作者确认精神一致）

### Constraints

- **不**注册 `drive` 为 LLM 可调用 skill
- **不**修改 `RobotInterface` 抽象（不新增 `move_to`/`turn` 实现）
- **不**在技能内部实现路径规划、避障、目标跟踪或 LLM 侧多步路径编排；**允许** skill 内部按固定公式拆成多段 `drive` 以满足总距离/角度（每段仍受 0.5s 限时）
- 所有运动仍受第九次安全门：`RDB_UNITREE_DRY_RUN`、`RDB_UNITREE_ENABLE_MOTION`、限速/限时 clamp
- 技能在执行前检查 `world.robot_self_state`（须 `RDB_PERCEPTION=unitree` 才有值）：未站立、error_code≠0（transport 映射后，非 MCF api echo）或状态过期时拒绝
- 技能不调用 `set_posture`（站立/趴下由操作者控制）
- `Skill.execute(..., robot: RobotInterface)` 签名不变；Go2 技能内 `isinstance(robot, UnitreeRobot)` 失败时返回 `SkillResult(success=False)`，不抛异常

### Success Criteria

- LLM 可通过 tool call 调用 `nudge`/`scan`/`retreat`；fake/dry-run 可测，live 需 confirmation + motion gate
- JSON Schema 正确暴露参数名、类型、范围、描述
- 前置检查失败 → `SkillResult(success=False)` + 结构化 `data.reason`，不抛异常
- `drive()` post-verify 失败 → `SkillResult(success=False)`；第九次升级 stop 已触发
- 参数超出范围 → skill 内 clamp，并在 `SkillResult.data` 记录 requested/clamped
- 长距离/大角度通过**多段 drive** 达成，总行程与请求值一致（在 clamp 后），无 silent 欠行程
- mock/fake 测试覆盖：前置拒绝、clamp、分段计划、单段/多段成功、后验失败、transport 异常
- generic 技能在 Go2 后端行为不变（见「已知限制」）
- 测试不低于 18 个新增用例，全量测试保持通过

## 设计方案

### 第九次限时约束（必读）

`UnitreeRobot.drive()` 将 `duration` clamp 到 `unitree_max_drive_duration`（默认 **0.5s**）。固定速度下**单段**上限：

| 通道 | 速度 | 单段最大位移 |
|------|------|-------------|
| 线性 nudge/retreat | 0.15 m/s | **7.5 cm** |
| 旋转 scan | 0.3 rad/s | **≈ 8.6°** |

因此 **50 cm nudge 需 7 段**、**90° scan 需 11 段**、**100 cm retreat 需 14 段**。技能层必须实现分段，不能假设一次 `drive(duration=distance/15)`。

### 技能设计

#### nudge — 短距平移

```
参数:
  direction: "forward" | "back" | "left" | "right"
  distance_cm: float = 20.0   (Pydantic + skill clamp: 10–50)

映射（分段）:
  distance_m = distance_cm / 100
  durations = plan_linear_segments(distance_m)
  forward → 每段 drive(vx=+0.15, duration=d)
  back    → 每段 drive(vx=-0.15, duration=d)
  left    → 每段 drive(vy=+0.15, duration=d)
  right   → 每段 drive(vy=-0.15, duration=d)

前置: robot_self_state 存在；is_standing；error_code==0；state_age < RDB_UNITREE_STATE_MAX_AGE_SECONDS
后验: 每段 drive() 自带 post-verify；任一段失败则整 skill 失败并 stop
```

#### scan — 原地旋转观察

```
参数:
  yaw_degrees: float = 45.0   (clamp: -90 ~ +90，正=CCW/左转)

映射（分段）:
  yaw_rad = radians(yaw_degrees)
  vyaw = +YAW_SPEED if yaw_rad > 0 else -YAW_SPEED
  durations = plan_yaw_segments(abs(yaw_rad))
  每段 drive(vyaw=vyaw, duration=d)

前置: 同 nudge（含 state_age）
后验: 同 nudge
```

#### retreat — 后退安全距离

```
参数:
  distance_cm: float = 30.0   (clamp: 10–100)

映射（分段）:
  distance_m = distance_cm / 100
  durations = plan_linear_segments(distance_m)
  每段 drive(vx=-0.15, duration=d)   # 始终后退，无前进分量

前置 / 后验: 同 nudge
```

语义：比 nudge 的 `back` 允许更大距离（100 vs 50 cm），且 LLM 不会误选 forward。

### 安全链

每个 Go2 技能的 `execute()` 链路：

```
0. isinstance(robot, UnitreeRobot)? 否 → SkillResult(success=False, reason=wrong robot type)

1. check_robot_self_state(world, settings)
   ├─ robot_self_state is None?     → 拒绝 (perception not unitree / no self state)
   ├─ is_standing == False?         → 拒绝
   ├─ error_code != 0?              → 拒绝（使用 transport 映射后的 error_code）
   └─ state_age > max_age?          → 拒绝

2. 参数 clamp → 计算 vx/vy/vyaw + plan_*_segments()

3. 循环 run_go2_drive_segments() / 逐段 robot.drive()
   ├─ 每段走第九次全链路: dry-run/clamp → precondition → lease → watchdog → post-verify → audit
   ├─ 任一段异常 → catch → SkillResult(success=False)；drive 内已 best-effort stop
   └─ 全部成功 → SkillResult(success=True, data=审计)

不在 skill 层再次读取 world.robot_self_state.is_moving——execute 节点不会自动 perceive，
读 world 会是 stale；后验完全依赖第九次 drive() 内的 transport read_state。
```

### SafetyValidator 扩展

```python
if skill_name == "nudge":
    if params["distance_cm"] > 50 or params["distance_cm"] < 10:
        return "nudge distance must be 10–50 cm"
if skill_name == "scan":
    if abs(params["yaw_degrees"]) > 90:
        return "scan angle exceeds ±90°"
if skill_name == "retreat":
    if params["distance_cm"] > 100 or params["distance_cm"] < 10:
        return "retreat distance must be 10–100 cm"
```

Validator 校验**请求值**上限；skill 内仍做 clamp 作为双保险。
