## Project Requirements

### Goal

创建一套 Go2 原生技能，映射到已有的 `drive(vx, vy, vyaw, duration)` 原语，通过完整的安全链路（clamp → precondition → drive → post-verify → audit）暴露给 LLM 作为可调用 tool。每个技能只做一件确定的事，速度和距离受限，不开放 raw `drive`。

### Existing Baseline

第十次迭代完成后：

- 执行层（第九次）：`drive()` 带 motion lease、generation 抢占、watchdog、try/finally 归零、前置检查、后验、审计
- 感知桥接（第十次）：`WorldState.robot_self_state` 含 is_standing、is_moving、error_code、sport_mode、velocity、imu_rpy、state_age_seconds
- 技能注册表：`SkillRegistry` 支持注册任意 `Skill` 子类，暴露 JSON Schema 给 LLM
- 安全校验：`SafetyValidator` 按 skill 名称白名单 + 参数限速/限距 + 急停/低电否决 + 确认要求
- 现有技能：`navigate`/`patrol`/`follow` 调用 `robot.move_to()`/`robot.follow()`——UnitreeRobot **未实现**这些方法，当前只在 mock 下可用

本轮不修改现有技能，不修改 `RobotInterface` 抽象。Go2 技能实现自己的 `execute()`，直接调用 `UnitreeRobot.drive()`。

### Features

- **nudge** — 单次短距平移。方向 forward/back/left/right，距离 10–50 cm，内部换算为 `drive(vx|vy, duration)`
- **scan** — 原地旋转观察。角度 ±90°，内部换算为 `drive(vyaw, duration)`
- **retreat** — 后退安全距离（10–100 cm），始终向后，无前进风险
- 每个技能执行全链路：参数 clamp → robot_self_state 前置检查 → drive → post-verify（is_moving=False）→ 审计
- 技能注册到 `SkillRegistry`，LLM 可通过 tool call schema 发现和调用
- `SafetyValidator._validate_motion()` 新增 nudge/scan/retreat 的速度/距离/时长上限校验
- mock robot 下技能可执行（走 dry-run 路径），fake transport 下可完整测试

### Constraints

- **不**注册 `drive` 为 LLM 可调用 skill
- **不**修改 `RobotInterface` 抽象（不新增 `move_to`/`turn` 实现）
- **不**在技能内部实现路径规划、避障、目标跟踪或自主决策
- 所有运动仍受第九次安全门约束：`RDB_UNITREE_DRY_RUN`、`RDB_UNITREE_ENABLE_MOTION`、限速/限时 clamp
- 技能在执行前检查 `world.robot_self_state`：未站立、error_code≠0 或状态过期时拒绝执行
- 技能不调用 `set_posture`（站立/趴下由操作者控制，不交给 LLM）

### Success Criteria

- LLM 可通过 tool call 调用 `nudge`/`scan`/`retreat`，发出真实 Go2 动作
- 每个技能的 JSON Schema 正确暴露给 LLM（参数名、类型、范围、描述）
- 前置检查失败时技能返回 `SkillResult(success=False)` 并附带结构化原因，不抛异常
- post-verify 失败时技能返回失败，且驱动层已执行升级 stop（第九次机制）
- 参数超出范围时 skill 内部 clamp 到合法值并记录到 audit
- mock/fake 测试覆盖：前置拒绝、参数 clamp、成功执行、后验失败、transport 异常
- 现有 generic 技能（navigate/patrol/follow）在 Go2 后端下的行为不变（仍调用 `move_to` → NotImplementedError，或明确报错）
- 测试不低于 15 个新增用例，全量测试保持通过

## 设计方案

### 技能设计

#### nudge — 短距平移

```
参数: direction: "forward" | "back" | "left" | "right"
      distance_cm: float = 20.0   (clamp: 5–50)

映射:
  forward → drive(vx=0.15, duration=distance/15)
  back    → drive(vx=-0.15, duration=distance/15)
  left    → drive(vy=0.15, duration=distance/15)
  right   → drive(vy=-0.15, duration=distance/15)

前置: is_standing==True, error_code==0, state_age < 2s
后验: is_moving==False (3s 超时, 否则升级 stop)
```

固定速度 0.15 m/s 远低于第九次的 0.2 m/s 上限，给 LLM 零超速可能。

#### scan — 原地旋转观察

```
参数: yaw_degrees: float = 45.0   (clamp: -90 ~ 90, 正=CCW/左转)

映射:
  vyaw = 0.3 if yaw>0 else -0.3
  duration = abs(yaw_degrees)*π/180 / 0.3

前置: is_standing==True, error_code==0
后验: is_moving==False
```

固定角速度 0.3 rad/s = 第九次上限，不超速。

#### retreat — 后退安全距离

```
参数: distance_cm: float = 30.0   (clamp: 10–100)

映射:
  drive(vx=-0.15, duration=distance/15)

前置: is_standing==True, error_code==0, state_age < 2s
后验: is_moving==False
```

始终 vx 负值（后退），无前进能力——特殊安全属性。比 nudge 的 back 方向距离上限更大（100 vs 50 cm），语义更清晰。

### 技能注册策略

新增 `skills/builtin/go2_catalog.py`，提供 `go2_skills() -> list[Skill]` 工厂函数。与现有 `default_skills()` 并列：

```python
def go2_skills() -> list[Skill]:
    return [NudgeSkill(), ScanSkill(), RetreatSkill()]
```

在 `AgentRuntime.create()` 中，当 `robot_backend == "unitree"` 时自动注册 Go2 技能（与 generic 技能合并）：

```python
all_skills = default_skills() + go2_skills()
skills = SkillRegistry(all_skills)
```

generic 技能（navigate/patrol/follow）保留在注册表中，但在 Go2 后端调用时会因 `UnitreeRobot` 未实现对应方法而报错——这是预期行为，不静默失败。

### 安全链

每个 Go2 技能的 `execute()` 链路：

```
1. world.robot_self_state 前置检查
   ├─ is_standing == False? → 拒绝 (robot not standing)
   ├─ error_code != 0?      → 拒绝 (robot in error state)
   └─ state_age > 2s?       → 拒绝 (stale state)

2. 参数 clamp → 计算 vx/vy/vyaw/duration

3. 调用 robot.drive(vx, vy, vyaw, duration)
   ├─ 内部走第九次全链路: dry-run/clamp → precondition → lease → watchdog → post-verify → audit
   ├─ 成功 → SkillResult(success=True)
   └─ 异常 → 已自动 stop; SkillResult(success=False)

4. 额外后验 (redundant with drive's own post-verify):
   读取 world.robot_self_state.is_moving, 确认停止
```

注意：第 3 步的 `drive()` 已经自带 post-verify 和失败自动 stop（第九次机制），所以第 4 步是冗余安全网。

### SafetyValidator 扩展

`SafetyValidator._validate_motion()` 新增：

```python
if skill_name == "nudge":
    if params["distance_cm"] > 50:
        return "nudge distance exceeds 50 cm"
if skill_name == "scan":
    if abs(params["yaw_degrees"]) > 90:
        return "scan angle exceeds ±90°"
if skill_name == "retreat":
    if params["distance_cm"] > 100:
        return "retreat distance exceeds 100 cm"
```
