Project Requirements
Goal
升级机器狗大脑的真实规划能力与可评测性：在现有常驻服务、任务调度、状态恢复和持久化基础上，引入真实 LLM Planner、语义记忆召回、任务复盘摘要和历史回放评测闭环，让后续接真机和扩展技能前先具备稳定的认知验证能力。

Features
支持通过配置切换 MockLLM、OpenAI 或兼容 LLM 接口
Planner 输出必须保持结构化，并继续经过技能白名单、安全校验和任务调度层
为长期经验增加语义召回能力，支持按目标、场景、失败原因检索相似经验
任务完成或失败后自动生成结构化执行摘要
支持按 thread_id 回放历史任务，包括消息、任务状态和世界状态快照
增加固定 mock 场景评测集，用于回归验证 Planner 行为
API 或状态页展示最近一次决策摘要：选择原因、引用记忆、安全拦截和下一步计划
Constraints
不接入真实机器狗 SDK，本轮仍以 mock 执行和 mock 感知为主
不允许 LLM 直接输出自由动作，所有动作必须映射到已注册技能
LLM 调用失败时必须可回退或明确失败，不能拖垮常驻服务
语义记忆第一版保持轻量，不引入复杂分布式向量数据库
保持 SQLite 本地持久化为默认方案
不引入多机器人、多用户权限和远程同步
Success Criteria
可以通过配置在 MockLLM 和真实 LLM 之间切换
Planner 的所有动作输出都能通过结构化 schema 校验
至少 5 条长期经验可写入并通过语义相似度召回
每个任务完成或失败后都有可查询的执行摘要
至少 3 个固定历史/模拟场景可以自动回放评测
状态页或 API 能查看最近一次 Planner 决策依据
完整自动化回归测试通过，并覆盖 LLM fallback、语义召回和回放评测流程
